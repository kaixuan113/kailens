# 发布与回滚

从 `20261021-01` 起，发布包保存在 `/opt/kailens/releases/<版本号>`。程序、前端构建和 Python 环境按版本隔离；数据库和上传图片始终留在原存储目录。

当前版本由 `/opt/kailens/current` 指向，发布与回滚操作追加记录到 `/opt/kailens/deploy/releases.jsonl`。每个版本的 `manifest.json` 记录说明和发布包校验值。第一次启用时，会将当时线上版本纳管为 `baseline-...`，并备份数据库、原始图片与前端。

## 在服务器终端执行

查看当前版本：

```bash
python3 /opt/kailens/deploy/release.py status
```

查看发布、失败恢复、回滚记录：

```bash
python3 /opt/kailens/deploy/release.py list
```

回滚到上一个成功版本（保留当前作品和照片）：

```bash
python3 /opt/kailens/deploy/release.py rollback
```

回滚到指定版本：

```bash
python3 /opt/kailens/deploy/release.py rollback 20261021-01
```

`20261021-01` 需要已存在且不是正在运行的版本；用 `list` 查询实际可用版本。回滚前再次备份当前数据库。发布或回滚后会重启 API，并检查 API、首页和后台页面；激活失败会尝试自动切回原版本。重启 API 期间可能有几秒请求中断。

## 直接告诉助手

- “把 kailens 回滚到上一个版本，保留现在的作品和照片。”
- “把 kailens 回滚到版本 20261021-01，保留作品数据。”
- “查看最近的发布记录和当前线上版本。”

程序回滚不会撤销你在后台对作品所做的修改。误删作品先从回收站恢复。数据库历史恢复是另一项操作，会影响备份之后的数据，需明确指定要恢复的数据和时间。

历史备份位于 `/opt/kailens/backups`。统一发布前的备份保留原样，早期记录不是完整的可直接切换版本。
